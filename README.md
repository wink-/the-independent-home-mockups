## Directions

1. Field Journal — rugged notebook, paper-first source material, monospaced transcript.
2. Independence Ledger — dashboard/stat-card view for monthly control-ledger updates.
3. Homestead Magazine — warm editorial direction for broader readers.
4. Terminal Paper Lab — tech-forward AI transparency / paper transcript direction.
5. Ephemera Board — kitchen-table clippings, receipts, scan scraps, and pinned notes.
6. Home Systems Blueprint — technical house-systems map for power, food, water, money, privacy.
7. Workshop Manual — calm lead-magnet/course funnel built around operating manuals and checklists.

Recommendation: use Field Journal as the base, then borrow Ledger stat cards, Workshop conversion sections, and Blueprint explainers as modules.
